# 行动项完成通知「聚焦显示」测试文档

> 对应需求/开发：同目录 `requirement.md`、`development.md`
> 形式：手工用例表（项目当前无自动化测试框架）

---

## 一、测试范围

- 完成通知卡片 → `/tracking?focusId=...` 聚焦展示
- 默认日期范围调整后的台账行为
- 权限与回归

## 二、环境与前置

- 环境：本地 `pnpm dev`（或测试服务器），已配置企微 OAuth（`WECOM_CORPID/WECOM_AGENT_ID`）。
- 账号：
  - 提出人（普通员工，如虞周峰）
  - 责任人（完成事项的人，如陈巧霞）
  - 系统管理员（陈巧霞）
- 数据准备：
  - A：会议日期 **>30 天前** 的已完成行动项，提出人=普通员工账号
  - B：会议日期 **30 天内** 的已完成行动项，提出人=同一账号
  - C：一项持续项（`due_date_type=continuous`）被标记完成
  - D：他人提出、与测试账号无关的已完成项

## 三、测试用例表

| 编号 | 用例 | 前置 | 步骤 | 预期 | 优先级 |
|------|------|------|------|------|--------|
| F1-01 | 聚焦显示旧会议完成项 | 数据 A | 用 A 提出人账号打开 `/tracking?shared=true&focusId=<A.id>` | 列表仅 A 一条；提示条"（1条）"；可见完成说明 | P0 |
| F1-02 | 聚焦显示近期完成项 | 数据 B | 同上，focusId=<B.id> | 仅 B 一条 | P0 |
| F1-03 | 查看全部台账 | 承接 F1-01 | 点提示条「查看全部台账」 | focusId 清除，恢复默认列表 | P1 |
| F1-04 | 聚焦项已无权限 | 数据 D | 用测试账号打开 `focusId=<D.id>` | 空态（0条），不报错，不泄露 D 内容 | P0 |
| F1-05 | 聚焦项不存在 | 任意 | 打开 `focusId=NOT_EXIST` | 空态（0条），不报错 | P1 |
| F1-06 | 默认日期范围 | 数据 A | 普通打开 `/tracking`（无 focusId） | A 可见（若方案 A 全默认全部）；或日期条显著展示当前区间（方案 B） | P0 |
| F1-07 | 主动筛选仍生效 | 数据 A/B | 无 focusId，选择责任人/状态/日期筛选 | 筛选结果正确，无串扰 | P1 |
| F1-08 | 持续项不发完成卡片 | 数据 C | 触发持续项"完成"（走稽核或自报） | 提出人**不**收到"✅你提出的行动项已完成"卡片 | P1 |
| F1-09 | 完成详情卡（可选） | 数据 B | 打开 focusId=B.id | 顶部出现完成详情卡（事项/责任人/提出人/截止/完成说明/时间/附件） | P2 |
| F1-10 | 移动端企微内打开 | F1-01 | 企微 App 内点卡片 | 布局正常、可见聚焦条 | P1 |
