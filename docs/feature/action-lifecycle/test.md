## 二、测试环境

- Web 浏览器：Chrome / Edge 最新版（桌面）
- 移动端：iOS Safari / Android Chrome / **企微内置浏览器**（关键）
- 账号：admin / manager / secretary / employee 各一；含 A（提出人）与 B（责任人）两个账号
- 数据：行动项 proposer 有值 / 为空 各若干条；含 done / pending / in_progress 状态
- 企微：配置好 CORPID / APP_SECRET，测试账号已加入企业微信
