> 版本：v2.0（定稿）  ·  状态：待实施

## 一、业务流程（完整闭环）

```
                    ┌─────────────────────────────────────┐
                    │  一条行动项，节点 9月10日，责任人张三  │
                    └──────────────┬──────────────────────┘
                                   │
          ═════════════════════════╪══════════════════════════
          到期前一天（9月9日）
                                   │
                  09:00 ──── 企微卡片推送给张三：
                             "您有 1 条行动项将于明天（9月10日）到期，请及时处理"
                             （卡片链接直达"我的任务"页，点开即可填报）
                                   │
          ═════════════════════════╪══════════════════════════
          到期日（9月10日）
                                   │
                    ┌──────────────┼──────────────┐
                    │                             │
              张三处理了 ✓                  张三没处理 ✗
              在系统填"已完成"                        │
              → 正常闭环，结束                        │
                                                     │
          ══════════════════════════════════════════╪══════════
          节点次日（9月11日）早上 09:00         │
                                                     │
            系统自动扫描 → 发现 9/10 已过仍未处理 ────┤
                                                     │
            ┌────────────────────────────────────────┘
            │
            ├── 动作1：原任务自动打 X（oa_score=-1, status=blocked）
            │         → 看板"打X项"区显示，张三完成率受影响
            │
            ├── 动作2：生成新行动项（复制原任务，责任人不变，节点为空）
            │         → 新任务出现在张三的"我的任务"待办里
            │
            └── 动作3：推企微卡片给张三：
                      "因节点到期未填写，已生成新行动项，请填写节点并处理"
                      （卡片链接直达"我的任务"页）
                                │
          ═══════════════════════╪══════════════════════════════
          后续
                                │
                ┌───────────────┼───────────────┐
                │                               │
          张三填了节点（如9/20）            张三一直不填节点
          → 新任务变 date 型               → 新任务一直留在"我的任务"待办里
          → 回到正常统计                   → 不进看板完成率（相当于"待定"状态）
          → 9/19 09:00 又会收到到期提醒     → 不会丢，但也不催（已确认不做额外催填）
           → 9/21 09:00 如还没做又打X+转派
          → 循环直到完成
```

## 二、两个自动化动作

### 动作 A：到期前预警

| 项 | 说明 |
|----|------|
| 触发时间 | 每天 **09:00**（北京时间） |
| 筛选条件 | 节点 = 明天 + 状态未处理 + 未打分 + 非群体 + 节点 ≥ 起始日期 |
| 推送内容 | 按责任人汇总一条企微卡片："您有 N 条行动项将于明天（M月D日）到期，请及时处理" |
| 推送链接 | 直达 `/mytasks`，责任人点开即可填报 |
| 防重复 | 同一条任务只提醒一次（记 `due_reminder_at` 时间戳） |

### 动作 B：到期后自动打X + 转派 + 推送

| 项 | 说明 |
|----|------|
| 触发时间 | 每天 **09:00**（北京时间） |
| 筛选条件 | ① `due_date_type='date'` 且 `due_date` 非空 ② `due_date` ≤ 昨天（节点已过）③ `status` 为 pending/in_progress ④ `oa_score` 为 null ⑤ 无 `reassignedTo` ⑥ 非 `isGroupOwner` ⑦ `auto_x_at` 为空 ⑧ `due_date` ≥ 起始日期 **2026-09-07** |
| 打X | `updateActionItem(id, { oaScore: -1, status: 'blocked', auto_x_at: now })` + 操作日志 |
| 建新任务 | 复制原任务（内容/责任人/提出人/部门），`due_date_type='tbd'`（节点为空），`due_date=null`，状态 pending，`reassignedFrom=原ID` |
| 推送 | 按责任人汇总企微卡片："因节点到期未填写，已生成新行动项，请填写节点并处理"，链接直达 `/mytasks` |

### 新任务（空节点）后续流转

| 情况 | 结果 |
|------|------|
| 责任人填了节点 | 自动变 date 型 → 回到正常统计 → 到期前又收到提醒 → 循环直到完成 |
| 责任人不填节点 | 一直留在"我的任务"待办列表里（不丢），不进看板完成率（相当于待定）|
| **不做额外催填** | 已确认：不催、不自动补节点、不上报 admin |

## 三、已确认参数（定稿）

| # | 参数 | 值 |
|---|------|-----|
| 1 | 起始日期 | **2026-09-07**（admin 可在页面调整，之前的不碰） |
| 2 | 到期前预警时间 | **每天 09:00** |
| 3 | 自动打X时间 | **每天 09:00**（与预警同一时间执行，先推预警再打X） |
| 4 | 新任务节点 | **为空**（tbd），责任人自行填写 |
| 5 | 推送方式 | 按人**汇总一条**企微卡片（不轰炸） |
| 6 | 试运行预览 | **要**（首跑必经，admin 确认后再执行） |
| 7 | 空节点不填 | **不做额外催填**（任务留在"我的任务"待办即可） |

## 四、涉及到的页面/模块影响

| 页面/模块 | 影响 |
|-----------|------|
| **我的任务**（/mytasks） | 责任人待办列表多出"空节点任务"，打开填报弹窗需先填节点日期 |
| **行动项台账**（/tracking） | 新增一批"由自动转派生成"的任务（reassignedFrom 有关联），节点列为空 |
| **周例会看板** | 打X项多出"系统自动打X"的记录（显示在打X区，有原节点值）；空节点新任务不进看板统计 |
| **月度/产销看板** | 同上 |
| **贡献榜** | 被自动打X的责任人：完成率下降（X 算未完成）；新任务不进统计（无节点） |
| **操作日志** | 每次自动打X/转派留一条 `auto_x` 日志，admin 可追溯 |

## 六、风险与对策

| 风险 | 说明 | 对策 |
|------|------|------|
| 首跑过多 | 起始日期后首日可能扫出多条 | 起始日期 2026-09-07 已定 + **首跑必经预览**，admin 确认数量再执行 |
| 误伤 | 责任人节点当天做完但没及时标 | 扫描条件严格（仅 pending/in_progress + oa_score=null）；如误打 admin 可手动改回 |
| 重复处理 | 同一条被多次打X+转派 | `auto_x_at` 时间戳硬防 + `reassignedTo` 互链 + `oa_score≠null` 排除 |
| OA 联动 | 现有转派函数会推 OA | 新写的流程**只走企微**，不碰 OA |
| 群体/无日期 | "所有人"或 tbd 不该被自动打X | 扫描条件显式排除 |
| 空节点"消失" | 不进看板统计 | 已确认：不做额外处理，任务留在"我的任务"即可 |

## 七、验收标准

### 到期前预警
- [ ] 节点 = 明天的任务，在 09:00 收到企微卡片（按人汇总）
- [ ] 卡片链接直达"我的任务"，可直接填报
- [ ] 同一条只提醒一次
- [ ] 起始日期之前的不会被提醒

### 到期后自动打X+转派
- [ ] admin 预览能看到"将处理 N 条、涉及 M 人"
- [ ] 执行后：原任务打X + 新任务生成（节点空）+ 转派链完整 + 企微推送到达
- [ ] 打X项在看板"打X区"正常显示（有原节点值）
- [ ] 新任务出现在责任人"我的任务"待办里，节点为空
- [ ] 责任人填节点后，新任务回到正常统计
- [ ] 同一条不会被重复处理
- [ ] 操作日志留痕，admin 可查
- [ ] 总开关可一键关

### 我的任务页
- [ ] 空节点任务的填报弹窗显示"请填写节点日期"必填项
- [ ] 填写节点后保存成功，任务变 date 型
