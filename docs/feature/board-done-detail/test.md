# 会议看板「已完成项」详情查看 测试文档

> 版本：v1.0  ·  状态：已实现（2026-09-03）
> 测试形式：手工用例表（项目暂无自动化测试框架）

## 1. 测试范围与环境

- 环境：本地 dev（`pnpm dev`，`http://localhost:5000`）；角色 admin/manager/secretary 均可看板。
- 涉及页面：`/weekly-board`、`/monthly-board`、`/production-board`。
- 数据前提：三块看板所选周期内需存在已完成行动项（部分用例依赖历史数据有完成说明/附件）。

| 编号 | 用例 | 前置 | 步骤 | 预期 | 优先级 |

## 3. 回归清单

- 三块看板翻页/自动播放/沉浸(F)/周期（周/月）偏移不受影响。
- 打X项"新节点"展示、持续项填报列、GSMALT 各页不受影响。
- `pnpm exec tsc --noEmit` 无类型错误。
- 无任何后端/接口变更，无需回归 OA 推送/回拉。
