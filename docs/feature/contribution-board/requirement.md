# 个人贡献绩效看板 需求文档 v1.3

> 版本：v1.3（已定稿）  ·  状态：已上线（2026-08-19 自测通过；2026-09-03 新增评分列）
> 创建：2026-08-19  ·  数据源：hyzs_action_items + hyzs_continuous_progress

## 1. 背景

老板要一个看板，统计每个人：每周/每月/每年接收多少任务、完成多少、完成率。用于识别高效产出与任务堆积的人。

数据：hyzs_action_items 1473 条，2026-01~2026-09。**已核实**：dept 94% 有值；completed_at 仅 17% 有值（不做耗时类指标）；cancelled 49 条（多为部门/群体责任人）。

## 2. 目标

按「人 × 时间粒度（周/月/年）」展示：接收任务数、完成任务数、完成率、未完成数、超期未完成数、待定数。支持部门筛选与排名。持续项按填报率单独板块展示。

## 3. 用户故事

| 角色 | 诉求 |
|------|------|
| 老板 | 看清每个人任务量与完成率，识别高效与滞后 |
| 管理者 | 看本部门成员贡献 |
| 个人 | 了解自己任务情况 |

## 4. 指标口径（已确认）

### 4.1 统计范围

- **只统计具体个人**名下的任务（排除"采购/研发/全体/各部门/品质部/生产部"等群体/部门责任人）
- 剔除 `cancelled`（取消）
- 剔除 `due_date` 为空（无节点无法归期）
- 持续项（continuous）不参与任务榜，单列填报率板块

### 4.2 统计周期归属

统一「计划口径」：接收与完成**都按 due_date 归属同一期**。

| 指标 | 归属 | 口径 |
|------|------|------|
| 接收任务数 | due_date | 该期到期任务 |
| 完成任务数 | due_date | 该期到期且 status='done' |
| 完成率 | — | 完成 / 接收 |
| 未完成数 | due_date | 该期到期且打X（oa_score=-1 / status='blocked'）|
| 超期未完成数 | — | 节点已过 + 未完成（打X + 超期未处理的待办）|
| 待定数 | due_date | 打0（oa_score=0），不计入完成率分子分母 |
| 评分 | — | 完成任务数 × 完成率（待定不计入完成率，故评分同口径排除待定）|

### 4.3 持续项填报率（单独板块）

| 指标 | 口径 |
|------|------|
| 应填报数 | 责任人名下持续项条数（该期）|
| 实际填报数 | 该期这些持续项中有填报记录的条数（**含提前填报免推的**）|
| 填报率 | 实际填报 / 应填报 |

### 4.4 不做

- 平均完成耗时 / 超期完成数（completed_at 缺失 83%；且填写时间≠实际做事时间）

### 4.5 排序

默认「评分」降序（评分 = 接收数 × 完成率）；可切换按完成数 / 接收数 / 完成率。

## 5. 统计粒度

周（ISO）/ 月 / 年，按 due_date 归属；支持切换 + 往前翻历史。

## 6. 页面结构

```
/contribution  个人贡献看板
├─ 顶栏：粒度切换 + 周期翻页 + 部门筛选
├─ 汇总区：总接收 / 总完成 / 平均完成率 / 总未完成
├─ 排行榜表格：排名|姓名|部门|接收|完成|完成率|未完成|超期未完成|待定|提出任务数|评分
├─ 个人明细弹窗：点姓名 → 该人该期任务列表（滚动）
└─ 持续项填报率：单独板块（姓名|应填|已填|填报率）
```

## 7. 数据来源

- hyzs_action_items（任务榜）+ hyzs_continuous_progress（持续项填报率）
- 部门取 dept 字段（缺失显示"未分配"）

## 8. 权限

- 仅 admin / manager 可见；老板投屏用 SlideFrame（可选）

## 9. 非功能

- SQL 单次聚合；前端做粒度/筛选切换
- 数据量小，性能无压力

## 10. 决策记录（已确认）

| # | 决策 | 结论 |
|---|------|------|
| 1 | 贡献主口径 | 责任人(owner)排名；提出人作"提出任务数"辅助列 |
| 2 | 周期归属 | 接收+完成都按 due_date（计划口径）|
| 3 | 完成口径 | status='done'；未完成=打X；打X重派不影响原任务当期末完成 |
| 4 | 耗时类指标 | 不做（completed_at 缺失 + 填写时间≠做事时间）|
| 5 | 超期未完成 | 保留（节点已过+未完成），后期可删 |
| 6 | 持续项 | 填报率板块（含提前填报免推）；提前填的算已填 |
| 7 | 取消/打0/群体 | cancelled 剔除；打0=待定列不计完成率；群体责任人排除 |
| 8 | 排序 | 默认评分降序（2026-09-03 起，原为完成任务数）|
| 9 | 权限 | 仅 admin/manager |
| 10 | 明细 | 弹窗滚动不分页 |
