# 月度看板·战略稽核（GSMALT）需求文档

> 关联代码：`src/app/api/gsmalt/route.ts`、`src/app/monthly-board/page.tsx`
> 路线图：`docs/feature/gsmalt-monthly-audit/`

## 1. 背景

公司战略目标落地情况在 OA（泛微 ecology）中用建模表 `uf_GSMALT`（主表）+ `uf_GSMALT_dt1`（明细）按月稽核维护，每条明细对应一项 KPI 行动计划，稽核标记 `jh`：**0=V（达标）、1=X（未完成）、2=0（待定）**，节点日期 `jd`。月度例会目前只能在 OA 里手工查表汇报，看板看不到战略稽核结果。

## 2. 目标

在月度看板（`/monthly-board`）中新增战略稽核内容，投屏时可直接汇报：

1. **X 项与未处理通报页**：数据月内打 X 的项 + 未稽核（未处理）项分块通报，含 KPI / 部门 / 责任人 / 原因分析 / 行动计划 / 策略 / 衡量 / **原节点 / 新节点**（与"未完成项通报"页风格一致：打X项红块、未处理项黄块）。
2. **汇总页**：V / X / 0 / 总项数统计卡 + 部门 V/0/X/未稽核 堆叠分布 + 稽核达成率（V÷(V+X)，0 项与未稽核不计入）。

## 3. 数据口径

| 项 | 口径 |
| --- | --- |
| 数据源 | OA 链接服务器 `FWsv.ecology.dbo`，实时直连（不落本地表） |
| 数据月 | `left(jd,7) = 数据月`；看板默认数据月 = 当前月 − 1，受 ‹ › 翻月控件控制 |
| 关联 | `uf_GSMALT a` ← `uf_GSMALT_dt1 b (a.id=b.mainid)` ← `uf_KPI c (b.clzbkpi=c.id)` / `hrmdepartment d (b.zrbm=d.id)` / `hrmresource e (b.zrr=e.id)` |
| 稽核映射 | OA `jh`：0→V、1→X、2→0（注意：与台账 `oa_score` 1/−1/0 约定不同，仅做前端展示映射，不改数据）；**空值（NULL/空串）→ 未稽核（未处理）**，不会被误判为 V |
| 「同一项」匹配键 | **同 KPI（clzbkpi）+ 同责任人（zrr）+ 同原因分析（yyfx2，去首尾空白，NULL 视为空串）** —— 业务确认 |
| 新节点（仅 X 项） | 全表中同匹配键的 `max(jd)`，且必须**晚于**原节点才显示，否则显示"—" |
| 排序 | 责任人（zh）→ KPI（zh） |

## 4. 功能范围

**含**：
- `GET /api/gsmalt?month=YYYY-MM`（默认上月），返回 `{ success, month, items[] }`，60s 内存缓存。
- 月度看板新增两页 slide：`战略稽核·X项通报`（第 2 页）、`战略稽核·汇总`（第 4 页）。
- 加载中 / 加载失败 / 无数据三种兜底展示；翻月自动重新加载。

**不含**：
- 不在台账（tracking/kanban）中编辑 GSMALT 数据（只读展示，数据维护仍在 OA）。
- 不做 V 项、0 项的明细页（仅汇总统计）。
- 不落本地库、不做定时同步。

## 5. 页面结构

```
/monthly-board（幻灯片）
├─ 1 未完成项通报（原有）
├─ 2 战略稽核·X项/未处理（新增）深红渐变头 + 分块表格（✕打X项 / 未处理项·未稽核，10 列）+ 底部 总/V/X/0/未稽核 统计栏
├─ 3 持续项·未完成（原有）
├─ 4 战略稽核·汇总（新增）4 统计卡 + 部门 V/0/X/未稽核 堆叠条 + 达成率环
└─ 5 总览（原有）
```

## 6. 接口

| 项 | 说明 |
| --- | --- |
| 路径 | `GET /api/gsmalt?month=YYYY-MM` |
| 鉴权 | 登录会话（middleware 统一校验，与其它 /api 一致） |
| 返回 | `{ success, month, items: [{ kpi, dept, owner, audit(0/1/2/null), jd, yyfx, xdjh, cl, hl, newJd }] }` |
| 错误 | 500 `{ success:false, error }`（链接服务器不可达等） |
| 缓存 | 服务端按 month 内存缓存 60s；`cached:true` 标识命中 |

## 7. 非功能需求

- 链接服务器单次查询 2 条 SQL（数据月明细 + 全表按键聚合 max(jd)），60s 缓存防连打。
- 看板其它页面不因 GSMALT 失败受影响（独立 fetch、独立兜底）。

## 8. 验收标准

1. 数据月（如 2026-08）有稽核数据时，通报页分两块列出打 X 项与未稽核项，字段完整。
2. X 项若在后续月份存在同匹配键更晚节点，新节点列显示该日期；否则显示"—"。
3. 汇总页 V/X/0/未稽核 数与明细页一致；部门分布、达成率计算正确。
4. OA 稽核列为 NULL/空串的记录归入"未处理项"，不计入 V。
5. ‹ › 翻月后两页数据随数据月刷新。
6. OA 不可达时页面显示错误提示，不影响其它幻灯片。
