# 月度看板·战略稽核（GSMALT）测试文档

## 1. 测试范围

- `/api/gsmalt` 接口（参数、数据、缓存、异常）
- 月度看板新增两页幻灯片（数据展示、翻月、兜底）

## 2. 环境与前置

- 环境：本地 `pnpm dev`，已配置 `DATABASE_URL` 且应用库配置了链接服务器 `FWsv`（或 `OA_LINKED_SERVER` 指向的实际名）。
- 前置：OA 中 `uf_GSMALT` 存在数据月记录（如 2026-08），含打 V/X/0 各若干项；至少一个 X 项在后续月份有同 KPI+同责任人+同原因分析 的更晚节点记录。
- 登录账号：任意可登录账号（middleware 会话校验）。

## 3. 测试用例表

| 编号 | 用例 | 前置 | 步骤 | 预期 | 优先级 |
| --- | --- | --- | --- | --- | --- |
| API-01 | 默认月份 | 已登录 | `GET /api/gsmalt` 不带参数 | 返回上月数据，`month` = 上月 YYYY-MM | P1 |
| API-02 | 指定月份 | 已登录 | `GET /api/gsmalt?month=2026-08` | 只返回 `left(jd,7)=2026-08` 的明细 | P1 |
| API-03 | 稽核值透传 | 数据月含 V/X/0 | 检查 items[].audit | audit 原值为 0/1/2，空为 null，不做别的转换 | P1 |
| API-10 | 稽核空值归一 | OA 中 jh 为 NULL/''/' ' 各一条 | 检查对应 items[].audit | 均为 null（未稽核），不误判为 V(0) | P1 |
| API-04 | X 项新节点（有更晚） | 某 X 项后续月份有同键记录 | 查该项 newJd | = 全表该键最大 jd，且晚于原 jd | P1 |
| API-05 | X 项新节点（无更晚） | 某 X 项是全表最新节点 | 查该项 newJd | null | P1 |
| API-06 | 匹配键含原因分析 | 同 KPI+责任人、原因分析不同 | 查两项 newJd | 互不串用对方的 jd | P2 |
| API-07 | 缓存 | 已登录 | 60s 内连续请求同月 | 第二次返回 `cached:true`，数据一致 | P2 |
| API-08 | 未登录 | 无会话 | 直接 GET /api/gsmalt | 401 `UNAUTHORIZED` | P1 |
| API-09 | 链接服务器异常 | 停用 FWsv/断网 | GET /api/gsmalt | 500，error=战略稽核数据查询失败 | P2 |
| UI-01 | 通报页分块展示 | 数据月有 X 项和未稽核项 | 打开 /monthly-board 第 2 页 | 深红标题「战略稽核·X 项与未处理通报」，分两块：✕打X项（红）逐行列 KPI/部门/责任人/原因分析/行动计划/策略/衡量/原节点/新节点；未处理项（黄）同列展示，新节点为"—" | P1 |
| UI-08 | 仅未处理无 X | 数据月只有未稽核项 | 第 2 页 | 打X块显示"无"，未处理块正常列表 | P2 |
| UI-02 | 新节点列联动 | API-04 数据 | 看该 X 项行 | 新节点列蓝字日期；无更晚节点显示"—" | P1 |
| UI-03 | 无 X 项 | 数据月无 X | 第 2 页 | 绿色对勾 +「无打X项」空态 | P2 |
| UI-04 | 汇总页统计 | 同 UI-01 数据 | 第 4 页 | 总/V/X/0 四卡数值与明细一致；部门堆叠条含未稽核灰色段且图例对应；达成率=V/(V+X)（0 与未稽核不计入） | P1 |
| UI-05 | 翻月联动 | 多月有数据 | 点 ‹ / › 切换数据月 | 两页数据与月份标签同步刷新 | P1 |
| UI-06 | 加载失败兜底 | 断开 OA | 打开看板 | 两页显示错误提示，其余幻灯片正常轮播 | P1 |
| UI-07 | 长文本 | 原因分析/行动计划很长 | 查看 X 项行 | 最多两行截断，悬浮 title 显示全文 | P3 |
