# 绩效面谈·未达成KPI · ✓ 已完成项详情查看 测试文档

> 版本：v1.0  ·  状态：已实现（2026-09-09）
> 测试形式：手工用例表（项目暂无自动化测试框架）

## 1. 测试范围与环境

- 环境：本地 dev（`pnpm dev`，`http://localhost:5000`）；角色 admin/manager/secretary 均可看板。
- 涉及页面：`/monthly-board` 的「绩效面谈·未达成KPI」页。
- 数据前提：所选数据月（默认上月）的 GSMALT 数据中存在 ✓ 已完成项（`audit===0`），且其中至少 1 条已同步进 `hyzs_action_items`（`source_type='gsmalt'`，含 `completion_note / oa_attachments`）。

## 3. 回归清单

- `/api/actions` 响应体新增 `original_id` —— 不影响其他消费方（字段为可忽略/null）。
- `/api/gsmalt` 响应体新增 `dt1Id` —— 不影响其他消费方。
- 月度看板「未完成项通报 ✓ 已完成项」/ 周例会 / 产销会 ✓ 已完成项：弹窗逻辑零改动（共用 `ActionDoneDetailDialog`）。
- 「✓ 已完成项」统计口径（目标/完成/完成率）不变（仍以 OA `audit===0` 为准）。
- GSMALT KPI汇总页（`gsmalt-stats`）：零改动。
- `pnpm exec tsc --noEmit` 无类型错误。
