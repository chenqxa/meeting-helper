# 操作日志（操作审计）测试文档

> 版本：v1.0  ·  对应需求：`requirement.md`  ·  对应开发：`development.md`
> 测试形式：手工用例表（项目当前无自动化测试框架）
> 环境：本地 `pnpm dev`（http://localhost:5000），数据库为共享 SQL Server

---

## 一、测试范围与环境

- 前置：以 admin（chenqiaoxia）登录；数据库中 `hyzs_operation_logs` 表已由启动迁移自动创建。
- 涉及页面：行动项台账 `/tracking`、持续项 `/continuous`、批次 `/batches`、会议详情、`/logs` 日志查询页。
- 数据准备：任选 1 条待稽核行动项、1 个批次、1 场会议。

## 三、回归清单（本次改动可能影响的既有功能）

| 回归项 | 说明 |
|--------|------|
| 行动项稽核 V/X/0 | tracking/continuous 按钮仍能正常设置/清除/锁定 |
| 行动项状态变更 | 打 V→done、X→blocked 后台账/待办展示正确 |
| 批量导入 | 导入后批次列表与台账正常 |
| 会议创建/锁定/删除 | 原有流程不受影响（日志为旁路） |
| `/api/operations` 接口 | 修表后不再报错，`OperationLog` 组件能显示 |
