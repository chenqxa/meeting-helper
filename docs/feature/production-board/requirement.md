# 产销会看板（/production-board）需求文档

> 版本：v1.0  ·  状态：已上线（未完成项通报 + 持续项 + 总览）
> 创建：2026-08-18  ·  负责人：admin

## 1. 背景

产销协调会（产销会）产出大量行动项与持续跟进事项（来源：会议纪要 `meeting_type='产销会'` + 批次导入 `source_text='产销会'`），目前只能在台账里翻查，缺少投屏演示场景。参照周例会看板/月度看板，新增产销会专属看板。

## 2. 目标

提供独立路由 `/production-board`，以 **PPT 幻灯片**形式呈现产销会待办与持续项，便于产销会现场投屏、逐项过会。

## 3. 用户故事

| 角色 | 诉求 |
|------|------|
| 管理者 | 产销会上投屏，一页看到本月未完成项与完成率，再逐页翻持续项进展 |
| 秘书 | 会前快速核对产销会持续项谁没填报 |

## 4. 功能范围

### 含
- 第 1 页 **未完成项通报**：上月到期未完成项（打X/未处理分块）+ 已完成板块 + 底部完成率（数据月=上个月）。
- 第 2 页 **持续项·未完成**：产销会来源持续项 + 最新周期填报内容（完整显示不截断，悬停看全文）。
- 第 3 页 **总览**：待办/已处理/本月到期/未完成项四卡 + 持续项统计 + 部门分布 + 优先级分布。
- 滑动/键盘/沉浸(F/Esc)/自动播放(6s) 交互，与周例会看板一致。
- 打0口径：打0（待定）项不归属任何板块、不计入完成率（与周例会看板一致）。

### 不含
- 看板内编辑数据（轻交互边界）。
- 导出 PPT。

## 5. 数据来源

- `GET /api/actions`（全量行动项）+ `GET /api/continuous/progress`（持续项周期填报）。
- 过滤：`meeting_type === '产销会'`；无会议的批次项以 `source_text='产销会'` 兜底计入持续项。
- 周期：按月（monthRange），数据月 = 上一个自然月。

## 6. 页面/路由结构

| 路由 | 内容 |
|------|------|
| `/production-board` | 3 页幻灯片（未完成通报 / 持续项未完成 / 总览） |

## 7. 入口与权限

- 侧边栏「业务协同 → 产销会看板」，roles: `admin / manager / secretary`（与周例会看板一致）。

## 8. 非功能需求

- 兼容 Chrome/Edge，投屏 1920×1080 与 4K 电视（SlideFrame 固定 1600×900 设计稿等比缩放）。

## 9. 验收标准

- [ ] 侧边栏出现「产销会看板」入口（admin/manager/secretary），employee 不可见。
- [ ] 第 1 页只显示产销会、上月到期的行动项；完成率 = 上月完成/目标（去取消、去打0）。
- [ ] 第 2 页显示产销会持续项及最新填报内容，长内容完整可见。
- [ ] 第 3 页统计口径与第 1/2 页一致。
- [ ] 键盘 ←/→ 翻页、F 沉浸、Esc 退出正常。
