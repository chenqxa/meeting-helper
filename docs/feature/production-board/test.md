# 产销会看板（/production-board）测试文档

> 版本：v1.0  ·  测试形式：手工用例表

## 1. 测试范围

入口权限、三页数据口径、打0排除、交互（滑动/键盘/沉浸/自动播放）、投屏缩放。

## 2. 环境

- 浏览器：Chrome/Edge 最新版；分辨率 1920×1080。
- 账号：admin（chenqiaoxia）、manager、employee 各一个。
- 数据：库中存在产销会行动项（含打V/X/0、超期、取消）与产销会持续项（含已填报/未填报）。

## 3. 测试用例

### 3.1 入口与权限

| 编号 | 用例 | 前置 | 步骤 | 预期 | 优先级 |
|------|------|------|------|------|--------|
