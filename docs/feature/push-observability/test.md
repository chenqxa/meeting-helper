# 推送可观测性与重试（统一 push_log + 企微自测）测试文档

> 版本：v1.0 · 测试形式：手工用例表（接口 + 企微实收）

## 1. 测试范围

四类推送日志落库、失败不标记 + 当天重试、企微自测、空 baseUrl 防护、死配置清理、现有推送回归。

## 2. 环境

- 本地 dev / 生产灰度：http://localhost:5000
- admin 账号（chenqiaoxia）
- 测试对象：陈巧霞、戎双娇、沈意玲（企微通讯录存在的真实用户）
- 工具：curl + 企微客户端实收确认

## 3. 测试用例

### 3.1 日志落库

| 编号 | 用例 | 前置 | 步骤 | 预期 | 优先级 |
|------|------|------|------|------|--------|
| N-01 | 持续项推送写日志 | 有持续项候选 | 触发持续项推送 | `hyzs_push_log` 有 `push_type=continuous`，含 oa/wecom 记录与 sent/failed | P0 |
| N-02 | 到期提醒写日志 | 有次日到期项 | 触发 `reminder-execute` | `push_type=due_reminder` 记录，逐责任人 success | P0 |
| N-03 | 打X写日志 | 有昨日到期未完成项 | 触发 auto-x execute | `push_type=auto_x` 记录 | P0 |
| N-04 | 待办推送写日志 | CHAT_TODO_PUSH_ENABLED=true | 触发待办推送 | `push_type=todo` 记录 | P1 |
| N-05 | 日志查询接口 | 已有日志 | GET /api/push/logs?type=due_reminder | 返回对应记录；非 admin 403 | P1 |

### 3.2 失败处理与重试

| 编号 | 用例 | 前置 | 步骤 | 预期 | 优先级 |
|------|------|------|------|------|--------|
| N-10 | 姓名未匹配不标记 | 候选责任人用一个企微不存在的人名 | 触发到期提醒 | 该责任人 `due_reminder_at` 为空；日志记失败 | P0 |
| N-11 | 失败当天重试 1 次 | 承 N-10 | 等待重试窗口 | 重试 1 次；仍失败则不无限重试 | P0 |
| N-12 | 成功才标记 | 企微正常责任人 | 触发到期提醒 | 送达成功者写入 `due_reminder_at` | P0 |
| N-13 | 空 baseUrl 防护 | 临时清空 NEXT_PUBLIC_APP_URL | 触发提醒 | 返回明确错误；不标记；日志失败 | P1 |
| N-14 | 幂等 | 同一天重复触发 | 再次触发提醒 | 已成功标记者不重复推 | P1 |
