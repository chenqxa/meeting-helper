# 测试文档：行动项企微直连推送与填写闭环

> 版本：v1.0
> 日期：2026-08-26
> 对应需求：`docs/feature/wecom-action-push/requirement.md`

---

## 1. 测试范围

企微直连通道（推送引擎 / apptodo 同步 / 企微填写 / 展现增强）+ 现有通道回归。
不含：自研 IM 功能测试（未改动，仅回归送达）、OA 表结构测试（未改动，仅回归同步结果）。

## 2. 环境

| 环境 | 配置 | 说明 |
|---|---|---|
| 本地 dev | `WECOM_TEST_MODE=true` + 白名单含测试账号 | 企微测试应用/真实应用白名单模式 |
| 灰度 | `WECOM_TODO_PUSH_ENABLED=true`，白名单 3 人 | 真实应用，真实待办中心 |
| 回退 | `WECOM_TODO_PUSH_ENABLED=false` | 验证零影响 |

前置条件：测试人在企微应用（AgentId 1000043）可见范围内；测试会议含行动项且责任人=白名单成员。

## 3. 测试用例表

### 3.1 阶段零：apptodo 接口语义验证

| 编号 | 用例 | 前置 | 步骤 | 预期 | 优先级 |
|---|---|---|---|---|---|
| T0-1 | create_todo 新建待办 | 测试脚本就绪 | 调 create_todo(todo_code=A) | 待办中心出现，字段正确（标题/详情/截止） | P0 |
| T0-2 | 同 todo_code upsert | T0-1 通过 | 改 summary/deadline 后再调 create_todo(todo_code=A) | **同一条待办原地更新**，不新增 | P0 |
| T0-3 | finish_todo 取消 | T0-2 通过 | 调 finish_todo(todo_code=A) | 待办消失或标记完成，不再提醒 | P0 |
| T0-4 | 超长 summary | — | summary 传 >20 字 | 不报错，正确截断 | P1 |
| T0-5 | 无效 userid | — | 接收人不存在的 userid | 返回错误码，脚本捕获不崩溃 | P1 |

### 3.2 M1 推送引擎

| 编号 | 用例 | 前置 | 步骤 | 预期 | 优先级 |
|---|---|---|---|---|---|
| T1-1 | 首次锁定推送待办 | 会议有 2 条行动项（责任人=白名单） | 锁定 | 责任人待办中心 +2 条；收到 1 条汇总卡片；快照表 +1 行 | P0 |
| T1-2 | 重复锁定幂等 | T1-1 完成 | 不解锁再锁定（或重放请求） | 无新增待办/卡片 | P0 |
| T1-3 | 无变化再锁定 | T1-1 后解锁→不改→再锁定 | 查看企微 | 待办无变化，无汇总卡片 | P0 |
| T1-4 | 修改后原地更新 | T1-1 后解锁→改截止日→再锁定 | 查看待办 | 截止日更新，**无新消息**，聊天流无叠加 | P0 |
| T1-5 | 删除后待办取消 | T1-1 后解锁→删 1 条→再锁定 | 查看待办 | 该待办消失/标记取消；无新消息 | P0 |
| T1-6 | 新增推新待办 | T1-1 后解锁→加 1 条→再锁定 | 查看待办 | +1 新待办，1 条汇总卡片 | P0 |
| T1-7 | 转派双向同步 | T1-1 后换责任人→再锁定 | 两人分别查看 | 旧责任人待办消失，新责任人 +1 | P1 |
| T1-8 | 已填写保护 | 某项已填完成说明 | 修改该项描述→再锁定 | 待办不动，无消息（保护） | P0 |
| T1-9 | API 失败不阻断 | 临时改错 secret | 锁定会议 | 归档成功，现有 4 路推送正常，失败入日志 | P0 |
| T1-10 | 总开关关闭 | `WECOM_TODO_PUSH_ENABLED=false` | 锁定会议 | 企微零消息零待办，其余通道正常 | P0 |
| T1-11 | 白名单外不推 | 会议责任人含非白名单人 | 锁定 | 仅白名单人收到 | P1 |
| T1-12 | 持续项/行动项区分 | 混合两类项 | 锁定 | 待办详情可见类型标识 | P2 |

## 4. 回归清单（现有通道，每轮必跑）

1. 锁定后 OA `uf_meetingplan` 同步结果（新增/更新/作废/保护）与改造前一致
2. IM 归档通知正常送达参会人；IM 待办清单正常送达责任人
3. 每日 09:00/17:30 定时待办推送正常
4. 解锁：OA 已填 wcjgsm 的项仍阻止解锁（逻辑未动）
5. 归档接口响应时间（叠加企微并行推送后 ≤ 原值 +3s）
