# 周例会看板（/weekly-board）测试文档

> 版本：v1.1  ·  测试形式：手工用例表（项目暂无自动化测试框架）
> 被测路由：`/weekly-board`  ·  数据接口：`GET /api/actions`

---

## 1. 测试范围

| 模块 | 覆盖点 |
|------|--------|
| 入口 | 侧边栏导航、台账页「演示」按钮 |
| 数据加载 | 接口拉取、加载态、空数据 |
| 第1页 统计汇总 | 四数字卡、部门分布、优先级环图 |
| 第2页 待办明细 | 卡片四字段、超期标红、空状态 |
| 占位页 | 展示与提示 |
| 滑动交互 | 拖拽、键盘 ←/→、圆点跳页、翻页箭头 |
| 沉浸模式 | F 进入、Esc 退出、按钮切换、全屏覆盖 |
| 自动播放 | 启停、6s 间隔、末页回首页 |
| 权限 | 角色可见性 |

## 2. 测试环境

- 浏览器：Chrome / Edge 最新版
- 分辨率：1920×1080（投屏）+ 1440×900（笔记本）
- 账号：admin / manager / secretary / employee 各一
- 数据：台账中存在 ≥10 条行动项，含未处理/已处理/已取消、含超期项、含多部门多优先级

## 3. 前置条件

1. 已登录，数据库 `hyzs_action_items` 有数据。
2. 至少 1 条 `due_date` 早于今天且 `status` 非 done（验证超期）。
3. 至少 1 条 `due_date_type = 'continuous'`（验证持续跟进标签）。
