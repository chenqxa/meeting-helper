## 一、系统入口

### 🔗 从 OA 进入

在泛微 OA 系统的菜单中，找到 **「会议纪要系统」** 并点击。

```
┌─────────────────────────────────────────────┐
│  泛微 OA                                    │
│                                             │
│  ├── 📁 流程管理                             │
│  ├── 📁 公文管理                             │
│  ├── 📁 知识管理                             │
│  └── 📋 会议纪要系统  ◄── 点击这里            │
│                                             │
└─────────────────────────────────────────────┘
```

> 💡 **提示**：也可以直接在浏览器地址栏输入：`http://192.168.0.127:18081/login`

│  │  │ 请输入您的 OA 账号  │  │    │

│  │                         │    │

### 📌 步骤 2：输入 OA 账号

在输入框中填写你的 **OA 登录账号**（不是姓名，不需要密码）。

| ✅ 正确示例 | ❌ 错误示例 |
|-----------|-----------|
| `chenqiaoxia` | `陈巧霞` |
| `zhangsan` | `张三` |
| `lisi001` | `李四@company.com` |

### 📌 步骤 3：点击登录

点击 **「登录」** 按钮，系统会：

```
  输入 OA 账号
       │
       ▼
  ┌──────────┐     ┌──────────┐     ┌──────────┐
  │ 发送账号  │────▶│ OA 校验  │────▶│ 获取姓名  │
  │ 到后端   │     │ 账号存在  │     │ 和部门   │
  └──────────┘     └──────────┘     └──────────┘
                                          │
                                          ▼
                                    ┌──────────┐
                                    │ 登录成功  │
                                    │ 进入首页  │
                                    └──────────┘
```

### 🔄 后续自动登录

> 首次登录成功后，**浏览器会记住登录状态**。
> 下次从 OA 点击菜单，会 **自动跳过登录页** 直接进入系统首页。
>
> 只有在以下情况才需要重新登录：
> - 登录状态过期
> - 清除了浏览器缓存
> - 更换了浏览器
> - 系统重新部署

## 四、上传会议材料

### 📌 操作步骤

```
  ① 点击上传区域 ──▶ ② 选择文件 ──▶ ③ 系统处理 ──▶ ④ 生成纪要
```

**支持的文件**：会议录音转写文本（.txt / .doc 等）

上传完成后，系统会自动：

| 步骤 | 说明 |
|------|------|
| 🔄 解析文本 | 识别会议内容结构 |
| 📝 生成摘要 | AI 提取会议要点 |
| ✅ 提取行动项 | 识别待办事项、负责人、截止时间 |
| 📊 置信度评估 | 对每条行动项标注识别可信度 |

### 🎯 置信度说明

| 标识 | 含义 | 操作要求 |
|:---:|------|---------|
| 🟢 **绿色** | AI 高度确信，信息完整 | 可直接确认 |
| 🟡 **黄色** | 部分信息可能不准确 | 建议检查后确认 |
| 🔴 **红色** | 信息缺失或不确定 | **必须**人工编辑补充后才能确认 |

  ☑ 截止时间已设定
  ☑ 低置信度（🔴）行动项已确认

## 九、常见问题

<details>
<summary><b>❓ 为什么只需要输入账号，不需要密码？</b></summary>

系统部署在公司内网，通过 OA API 校验账号真实性，并自动获取姓名和部门信息。内网环境下无需额外密码验证。

</details>

<details>
<summary><b>❓ 输入账号后提示"登录失败"怎么办？</b></summary>

请检查：
- 是否输入的是 **OA 登录账号**（如 `zhangsan`），不是中文姓名
- OA 系统是否正常运行
- 网络是否正常

仍有问题请联系 IT 支持。

</details>

<details>
<summary><b>❓ 为什么有时需要重新登录？</b></summary>

以下情况登录状态会失效：
- 浏览器 Cookie 过期
- 清除了浏览器缓存
- 更换了浏览器或电脑
- 系统重新部署

重新输入 OA 账号即可。

</details>

<details>
<summary><b>❓ 为什么不是完全自动的单点登录？</b></summary>

当前 OA 系统版本不支持向第三方外链传递用户身份 Token。我们已与 OA 对接 API 认证，首次输入账号后浏览器会保持登录状态，体验接近单点登录。

后续如 OA 升级或开放 SSO 回调能力，可实现完全无感登录。

</details>
